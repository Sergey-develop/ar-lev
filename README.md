# LEV — AR в браузере без маркера

На телефоне откройте сайт, нажмите «Открыть камеру» и разрешите камеру/движение. Медленно наведите телефон на пол с хорошо различимыми деталями. Лев автоматически размещается после стабилизации отслеживания. QR нужен только для перехода по ссылке; держать его в кадре не требуется. «Рычать» включает синтезированный звук. «Переставить» выбирает новое место.

Используется новый пользовательский base.glb (без встроенных анимаций), Three.js и оригинальный 8th Wall Distributed Engine Binary 1.0.0 с SLAM. Это камера и отслеживание пространства внутри страницы, а не Quick Look, USDZ, HIRO или приклеенный к экрану объект. При потере трекинга позиция льва не пересоздаётся; страница просит восстановить трекинг.

Работа зависит от освещения, деталей поверхности и возможностей телефона. Проверка на физическом iPhone ещё необходима. На компьютере показывается QR вместо попытки запустить неподдерживаемое отслеживание.

Команды: npm install; npm run dev; npm run build. Статическая сборка для GitHub Pages — github-pages/. Все пути относительные, чтобы работать в /ar-lev/. Модель и движок загружаются с этого же хостинга. Нет записи видео, собственного сервера или загрузки видеозаписи.
